ORACLE PWA (LT / EN)

IMPORTANT: Opening index.html directly from Downloads will NOT install a PWA. Upload the entire folder contents to an HTTPS website, then open its HTTPS address in Chrome on Android and select menu (three dots) > Install app / Add to Home screen.

Simple hosting: create a GitHub repository and upload all files preserving icons/ folder, enable GitHub Pages in Settings > Pages, then open the published URL. Alternatively use any static HTTPS hosting that supports service workers.

After the first successful online load, the app can work offline. Hosting link is accessible to anyone with the URL unless you add access controls.
